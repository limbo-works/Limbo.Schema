### Installation

Install the package via [**NuGet**](https://www.nuget.org/packages/Limbo.Schema). To install the package, you can use either .NET CLI:

```
dotnet add package Limbo.Schema -prerelease
```

or the NuGet Package Manager:

```
Install-Package Limbo.Schema -pre
```
